# R-TYPE TACTICS ダメージシミュレータ

[English README is available here](README.en.md)

R-TYPE TACTICSの各種武器の攻撃・迎撃・反撃のダメージや回避率をシミュレートします。いろいろなデータを解析して作っています。

アクセスはこちら:

- https://106-.github.io/r-type-tactics-damage-simulator/
- https://r-11s2.vercel.app/

## できること

- ゲーム中に登場する任意の攻撃者と被害者を対象とした、命中時ダメージの最小・RNG平均・最大
    - 属性相性、実効地形防御、迎撃による被ダメ減衰率
    - ユニットの損耗・熟練度・ノックバック判定に基づく攻撃力の変化の適用
    - 体当たり攻撃の攻撃側へのダメージ
- ユニット設定に基づく回避率の計算
    - 熟練度・地形による変化

## ダメージシステム詳細

### 01 戦闘フロー

1. **攻撃成立** — 攻撃武器・通常/反撃・射程などを決定
2. **迎撃** — 対象攻撃だけ武器対武器の減衰率を算出
3. **命中判定** — 実効回避率に対する乱数1回で命中判定
4. **HPダメージ** — 武器威力、編隊、迎撃、威力乱数、地形防御、属性相性を適用
5. **追加処理** — ノックバック衝突、編隊機数、演出用の表示値を更新

```
ダメージ ≈ 武器威力 × 編隊率 × (1−迎撃率) × 威力乱数 × (1−実効地形防御) × 属性相性
```

ダメージの威力乱数は下記の範囲内から一様乱数に従って選ばれます。通常攻撃ではダメージが下振れ、一方反撃ではダメージが上に振れます。

| 威力乱数 | 範囲 | 平均 |
| --- | --- | --- |
| 通常攻撃RNG | 57.5～100% | 78.75% |
| 反撃RNG | 100～142.5% | 121.25% |

### 02 回避・命中

```
実効回避 = 対象回避 + [回避専念時: 対象回避 × 0.5 / 占有HEX数] + 地形回避 − 武器命中
```

0～100%に制限後、一様乱数で比較します。"回避に専念"すると、`基礎回避率 x 0.5 / 占有HEX数` を加算します。反撃・迎撃時はこのボーナスを受けません。

> **ゲーム内UIの表示について:** 「回避・防御に専念する」はいつも「回避率 +25%」と表示されていますがこれは表示ミスなようです。実際の専念ボーナスは基礎回避率と占有HEX数から別途計算されています。

複数HEXユニットの地形回避は、占有HEX全体ではなく**ユニットの基準HEX（マークがあるHEX）の地形だけ**を参照します。

#### 必中設定

```
必中設定あり → 回避率 0% / 命中率 100%
```

主にチャージ武器など、必中設定されている攻撃は対象回避・地形回避・武器命中による通常の回避計算を通りません。

- **表示命中値が100%未満でも必中です。** アイビーロッドは表示75%ですが、必中設定の対象であるため実戦では回避計算を通りません。

### 03 属性相性

このゲームの武器と機体にはそれぞれ属性が設定されています。武器属性は8種類ある一方、機体属性は5種類あります。この組み合わせが武器ダメージの増幅と減衰を決定しています。

| 対象系統 | 光学 | 機械 | 生体 | 粒子 | 火炎 | 精神 | 氷 | 酸 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 機械 | ±0 | ±0 | +20% | ±0 | ±0 | ±0 | +10% | +10% |
| 生物 | +10% | +20% | ±0 | +10% | +25% | +15% | +15% | +15% |
| 岩石 | ±0 | ±0 | ±0 | ±0 | ±0 | ±0 | ±0 | ±0 |
| 氷 | +10% | ±0 | −10% | ±0 | +30% | ±0 | ±0 | ±0 |
| 異質 | ±0 | ±0 | ±0 | ±0 | ±0 | ±0 | ±0 | ±0 |

"異質"はグリッドロックや琥珀色の瞳孔などに振られています。

### 04 地形

- **地形回避**は命中判定のブロック率に固定加算されます。
- **地形防御**は命中後のダメージ減衰です。光学属性にのみ適用され、機械属性（ミサイルなど）は無視します。

### 05 迎撃

機械・生体・氷属性の攻撃に対して、対象が持つ迎撃武器が候補になります。

```
未補正迎撃率 = (迎撃武器威力 / 攻撃武器威力) × (迎撃側現在HP / 最大HP) × (攻撃側最大HP / 現在HP) × 迎撃武器命中
```

| 未補正迎撃率 | 適用値 |
| --- | --- |
| 10%未満 | 10%（最低迎撃率） |
| 10～90%未満 | 計算値のまま減衰 |
| 90%以上 | 100%（完全迎撃） |

鹵獲弾は例外的に迎撃率0%です。迎撃は地形防御より前に処理されます。

#### 体当たりに対する迎撃

体当たり・フォースシュートを迎撃すると、対象側ダメージの減衰に加えて攻撃側に反動ダメージが入ります。

```
反動 = 攻撃側現在HP × 迎撃率 × 0.85（最低25・最大115）
```

体当たり・フォースシュートなどはノックバックを発生させます。移動先が地形またはユニットで塞がっていると追加基礎ダメージ **+25** です。

反動は最低25、最大115。この反動で攻撃側が撃破される場合、対象側への体当たりダメージは0になります。

### 06 鹵獲

鹵獲弾は通常の武器命中・対象回避計算とは別の専用判定を使います。

```
鹵獲可能条件: 残HPが25%以下 or 残燃料が40%以下
```

| 状況 | 鹵獲成功率 |
| --- | --- |
| 通常時 | 60% |
| 回避扱い | 15% |
| HP・燃料条件外 | 0%（鹵獲不可） |

- **HP25%より減らしても成功率は上がりません。** 残HP25%でも1%でも、通常60%・回避扱い15%です。

### 07 その他

**戦闘アニメーションの補正矢印アイコン:** 算出済みの実ダメージと、地形防御・属性相性・条件補正などを外し、同じ威力乱数で再計算した比較用ダメージとの比率を、🔼/🔽の1～3個で表示します。矢印方向は防御側基準（おそらく）であり、🔼はダメージ減少、🔽はダメージ増加を示します。

- **表示なし:** 補正率の絶対値が0.01%未満
- **🔼 / 🔽:** 0.01%以上、10%未満
- **🔼🔼 / 🔽🔽:** 10%以上、20%未満
- **🔼🔼🔼 / 🔽🔽🔽:** 20%以上
